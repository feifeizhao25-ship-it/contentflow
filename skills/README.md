# Skills 状态说明

此目录此前包含一个仅剩 9 行、无法解析或执行的 `_skill_impl.py` 残片。它不是生产 Skill，也未被 `runtime/` 部署栈引用，现已删除，避免验收时把残片误判为可用能力。

当前生产内容能力以 `runtime/api/src/modules/ai` 中受 JWT、租户额度、成本记录和合规过滤保护的 API 为准。内容包接口在没有 RAG 检索时必须返回：

- `sources: []`
- `sources_status: "none"`
- 明确说明本次未引用外部知识库

在重新启用任何 RAG Skill 前，必须同时完成：

1. 为每个知识条目保存 HTTPS 来源、来源名称、发布时间、抓取时间、适用法域、来源等级及人工复核状态。
2. 使用 `scripts/validate_rag_freshness.py` 做生产失败关闭；不得使用 `--allow-empty` 声称 RAG 已上线。
3. 在输出中展示实际使用的来源，不得把未进入模型上下文的资料列为引用。
4. 对新闻、政策、平台规则、模型价格等时效数据设置更新期限和失效状态。
5. 每个 Skill 都要有输入校验、权限/额度校验、模型与版本记录、来源断言、无资料状态和回归测试。

在上述条件完成前，产品可以提供“无外部来源的 AI 草稿”，但不得宣传为“已引用知识库”或“经过 RAG 验证”。
