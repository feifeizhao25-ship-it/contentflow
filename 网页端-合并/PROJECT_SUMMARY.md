## 🚀 快速启动

### 1. 安装依赖
```bash
cd fenfa-ai
npm install
```

### 2. 配置环境变量
```bash
cp .env.example .env.local
# 编辑 .env.local 填写 Supabase 配置
```

### 3. 启动开发服务器
```bash
npm run dev
```

访问: http://localhost:3000

## 💡 关键技术决策

### 1. 为什么选择 Next.js 14？
- ✅ App Router 提供更好的路由体验
- ✅ 服务端渲染（SSR）提升 SEO
- ✅ API Routes 简化后端开发
- ✅ 优秀的开发体验

### 2. 为什么选择 Supabase？
- ✅ 开箱即用的认证系统
- ✅ PostgreSQL 强大的查询能力
- ✅ Row Level Security 完美支持多租户
- ✅ 实时订阅功能
- ✅ 免费额度适合 MVP

### 3. 为什么选择 Ant Design？
- ✅ 企业级 UI 组件库
- ✅ 中文文档完善
- ✅ 组件丰富且成熟
- ✅ 主题定制灵活
