## 📝 使用说明

### 1. 配置环境变量

复制 `.env.example` 到 `.env.local`：
```bash
cp .env.example .env.local
```

编辑 `.env.local`，填写必要的配置：
```bash
# Supabase（必需，用于认证）
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key

# AI 服务（可选，用于 AI 生成功能）
OPENAI_API_KEY=sk-your-openai-key
# 或使用通义千问
DASHSCOPE_API_KEY=sk-your-dashscope-key
NEXT_PUBLIC_AI_PROVIDER=openai  # 或 dashscope
```

### 2. 启动应用

```bash
npm run dev
```

访问: http://localhost:3000

### 3. 测试功能

#### 测试登录/注册
1. 访问 `/register` 注册新账号
2. 查收邮箱验证邮件
3. 访问 `/login` 登录

#### 测试 AI 生成
1. 访问 `/ai-create`
2. 输入主题（如"AI内容创作"）
3. 选择写作风格
4. 点击"AI 生成文章"或"生成爆款标题"

#### 测试发布功能
1. 访问 `/publish`
2. 选择内容
3. 选择平台
4. 选择立即发布或定时发布
