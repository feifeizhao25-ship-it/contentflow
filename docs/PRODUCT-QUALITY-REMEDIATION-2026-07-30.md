# 分发侠产品质量全面修复建议与验收标准

日期：2026-07-30
范围：国内版、国际版、Web、Android、iOS、API、Skills、RAG、报告导出

## 产品原则

1. **事实先于文采**：事实性表述必须能回到编号来源；没有证据时明确写“建议”或“尚未核实”，不得用模型自信度代替真实性。
2. **国际版独立设计**：国内版围绕小红书、抖音、微信、知乎的创作与分发；国际版围绕 TikTok、YouTube、Instagram、LinkedIn 的市场适配、团队审核、品牌安全与证据链，不做逐句翻译。
3. **默认让普通人看懂**：结论在前，专业术语首次出现时解释；一屏一个重点；复杂依据放入可展开区域。
4. **个性化可解释、可关闭**：明确说明推荐原因、使用了哪些数据，支持修改画像、清除标签、关闭个性化。
5. **自动改进不能自动上线**：候选资料只能经过发现、许可核验、隔离、评测、人工批准、版本发布后进入生产，并保留回滚点。

## 19 项要求对应的代码验收

| 主题 | 必须通过的验收 |
|---|---|
| 输出准确性 | 编号引用覆盖、来源可点击、过期资料 fail-closed、黄金样例＋反例＋人工抽检 |
| 文化差异 | 国家/平台/角色三层画像；禁忌、语气、日期货币和行动偏好按市场配置 |
| 通俗表达 | 摘要、关键数字、下一步三层信息；阅读难度与术语解释测试 |
| 中英文隔离 | 国内源码与响应不出现面向用户的英文；国际源码与响应不出现中文；CI 阻断 |
| 国际 UI | 信息架构、平台组合、合规提示、付费方式与案例全部独立 |
| 会员权益 | 套餐、配额、团队席位、导出、API、品牌声音、审核、超额提示保持单一事实源 |
| Skills / RAG | 每次响应记录 skill id/version、source id/date/url、参数摘要和执行状态 |
| 时效性 | 平台规则 30 天、监管 90 天、稳定标准 365 天；到期自动下线而非继续回答 |
| 公式/图片/视频 | KaTeX、可访问图片说明、视频字幕/封面/失败状态；不支持时明确降级 |
| UI 编排 | “结论→证据→行动”，限制同屏主卡数量，详情渐进展开 |
| 全场景调用 | 建立场景清单覆盖生成、适配、审核、发布、分析、报告及失败分支 |
| 合规 | 中国生成内容标识/算法与数据义务；国际 GDPR、EU AI Act、FTC、COPPA/未成年人 |
| 个性化 | 冷启动问答、显式偏好、行为信号、置信度衰减、解释与退出 |
| 视觉质量 | 桌面、平板、手机真实浏览器截图；键盘、对比度、溢出和空状态检查 |
| 报告导出 | DOCX/PDF 目录、标题层级、页眉页脚、表格不溢出、来源附录、逐页渲染 QA |
| 五用户七天 | 五种职业角色、D1 冷启动→D7 周报，首页顺序、Skill、行动与置信度每天变化 |

## 本轮已落地

- 平台资料超过 30 天未核验时不再进入默认生成上下文。
- 质量评分不再因为“附带了来源列表”就给满引用分；正文必须出现编号、发布者或链接。
- 国内/国际生成提示分别要求中文/英文，并要求平台事实与编号来源对应。
- 国内与国际 Web 均加入“五用户 × 七天”交互验收页；两版角色、目标、平台和视觉体系独立。
- 持续改进状态机继续保持“人工批准 + 0.85 证据/安全阈值 + 可回滚”。

## 上线闸门

任何一项出现以下情况即停止发布：生产返回模拟值；过期资料进入默认答案；国际版出现中文或国内版出现面向用户的英文；事实没有来源却显示“已核实”；会员扣额早于任务受理；报告未完成逐页渲染检查；真实浏览器关键路径失败；密钥进入 Git 历史。
