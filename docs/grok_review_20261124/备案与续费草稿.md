# 草稿，待主人定：备案号、自动续费、注销和撤销授权

默认不上线。本文件不替换现有用户协议、隐私政策或定价页。页脚不写备案号，除非主人另行配置。

## 备案号

正式环境的 ICP 备案号由主人填写。未填写时页脚保持现在的「用户协议 / 隐私政策」，不显示占位号。

## 自动续费（拟定，未放上定价页）

当前没有自动扣款。开通后的有效期写在订单上，到期后回到免费版额度。如果以后要自动续费，页面需要同时写清：扣费周期、价格、取消入口，以及扣费前的提醒。这些句子定稿前不能当承诺。

## 注销和撤销授权

设置里如果已经有导出和注销入口，保持现有流程，不在这份草稿里改文案。账号页已有「解绑」。解除授权后，本产品不再用该账号发布；平台侧的授权是否还在，要到对应平台里再看。是否要求手机号实名，请法务确认。
