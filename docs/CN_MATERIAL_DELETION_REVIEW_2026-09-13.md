# 国内素材删除结果核验

本轮修复网页素材库的真实删除链路：原实现忽略 Storage.remove 的错误，随后删除数据库记录并提示成功，可能造成文件残留且无法从素材库重试。

现在先验证当前用户的素材记录、同源存储 URL 与用户目录，正确解码中文文件名；存储失败时保留记录。数据库删除要求返回目标行，未删除任何行不得报告成功。所有权条件同时用于读取与删除，服务端仍须启用正确的 RLS 和 Storage 策略。

新增 8 个可执行回归场景，覆盖中文文件、存储错误、数据库错误、零行删除、无记录、跨用户 URL、外部域名及编码路径穿越；加入 npm test。网页 npm test 与 TypeScript noEmit 均通过。

限制：Storage 与数据库不是一个事务；文件已删除而数据库失败时仍保留记录并报告失败，需重试清理记录。本轮使用客户端替身核验错误链路，尚未在生产 Supabase/阿里云存储验证真实策略、网络失败与实际文件删除；没有删除用户真实素材，也未进行网页截图验收。
