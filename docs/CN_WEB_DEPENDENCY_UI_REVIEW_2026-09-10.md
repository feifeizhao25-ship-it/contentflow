# 国内网页依赖与会员页修复

本轮修改 `runtime/web-cn`，不代表国际版、全部旧网页目录或四项目完成验收。

- Next.js 与 eslint-config-next 固定为 16.3.4，更新 sharp 及兼容范围内的依赖锁定结果。富文本编辑器整套迁移至 3.31.3，明确内容同步不再次触发更新，工具栏随事务刷新并提供中文无障碍标签。
- 四档会员卡片统一显示服务端方案或同源权益注册表，恢复企业版每月 1999 元及对应权益，移除另写的“企业定制”卡片与未启用的服务承诺。没有更改已购订单或后台套餐价格。
- 移除“升级无限额度”、无时限的早鸟促销及未核实的自动退款、补差价、开票种类承诺。常见问题使用中文说明，手机卡片不再额外放大。
- 国内网页 Docker 构建增加公开后端参数；发布工作流从 `CN_SUPABASE_URL` 仓库变量和 `CN_SUPABASE_ANON_KEY` Secret 传入。要求 HTTPS、非 `.invalid` 地址及非空匿名公钥。此公钥会进入浏览器包，禁止填写服务端管理密钥。上线前须确认服务部署地域及国内数据处理方案；本轮没有新建该后端服务。

依据：[Next.js 维护者安全公告](https://github.com/vercel/next.js/security/advisories/GHSA-2xp9-vwfh-vxw4)、[sharp 维护者安全公告](https://github.com/lovell/sharp/security/advisories/GHSA-rgj7-g3m4-5g8c)、[编辑器安全公告](https://github.com/advisories/GHSA-cp6q-959q-f8rh)、[编辑器迁移指南](https://tiptap.dev/docs/guides/upgrade-tiptap-v2)。查阅日期 2026-09-09 至 2026-09-10。
