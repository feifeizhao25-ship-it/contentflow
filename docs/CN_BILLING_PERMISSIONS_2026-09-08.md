# 国内账单操作权限

账单下单、取消续费、关闭订单和申请退款原先只要求登录，工作区普通成员也能调用。现在每次操作查询当前数据库账号，要求身份、工作区、active 状态及 owner/admin 角色一致，不信任请求体角色或可能过期的 JWT 角色。缺少用户/工作区标识时在 ORM 查询前拒绝，避免 undefined 过滤条件扩大查询范围。

账单只读及验签后的供应商回调不改变。此处 owner/admin 是本轮采用的账单管理员规则，尚未增加自定义财务角色。订单内部仍按工作区过滤。

验证：账单相关 39 项、全 API 137 项测试通过；TypeScript noEmit 通过。新增 12 项覆盖四种操作的身份缺失、旧 owner 令牌已被撤权、允许角色以及请求体伪造工作区。测试数据库访问为受控替身，没有声称完成生产账号端到端验收。

后续：订单状态检查与更新的并发竞争、实际数据库的回调/退款事务、财务权限 UI、支付参数与真实商户联调仍需继续处理。本轮没有真实付款或生产发布。
