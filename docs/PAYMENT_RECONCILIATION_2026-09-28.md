# 支付平台查询与关单确认

新增支付宝、微信订单查询和关单适配器，以及管理员专用 POST /billing/orders/reconcile。查询已付款时按原订单金额和渠道执行现有事务开通；同一交易以查询、回调等不同事件到达不重复开通。查询失败或响应验签失败不改变本地状态。

关闭在线支付订单前先查询平台；已支付则补齐权益并拒绝关单，未支付须收到平台关单确认才关闭本地订单。平台已关闭可同步本地状态。微信验签原始响应并核对应用、商户、订单号；支付宝使用官方 SDK 验签且绑定订单号。SDK 的 urllib 依赖锁定 4.9.1，生产依赖审计 0 漏洞。

会员页超时提示增加“我已付款，重新核对”按钮，仅传订单号，仍由后端验证和授予权益。

## 验证

40 组 240 项 API 测试通过；API 构建、修改生产源文件 ESLint 通过；网页全部脚本测试及生产构建通过；本地 PostgreSQL 15 个并发场景通过。数据库脚本中的平台查询/关单为显式替身，不调用商户接口；微信测试使用本地生成的真实 RSA 签名，包括错误归属、篡改响应、未签名 204。支付宝 SDK 调用采用替身，确认必须传 validateSign，不声称商户验收通过。本轮未截图新增超时按钮。
