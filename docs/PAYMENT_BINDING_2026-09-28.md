# 支付回调与退款权益归属修复（2026-09-28）

## 已修复

- 支付渠道必须是微信、支付宝或对公转账，并与订单原定渠道一致；其他渠道即便已验签也不能激活权益。
- 重复回调事件必须绑定原订单；同一事件编号用于另一订单时报冲突。原订单的重复事件仍正常确认，不重复授予权益。
- 退款订单必须关联订阅。撤销订阅同时限定订阅 ID 和租户 ID，并确认更新了一条记录，之后才允许降级该租户和完成退款。缺失或错误关联时停止处理，交由人工核对。

## 验证

新增 8 项场景测试，包括跨渠道、未知渠道、跨订单事件复用、正常重复事件、退款缺少关联、错误归属和正常退款。已有付款成功和状态竞争测试继续通过。

`npm --prefix runtime/api test -- --runInBand`：37 组、212 项通过。

`npm --prefix runtime/api run build`：通过。
