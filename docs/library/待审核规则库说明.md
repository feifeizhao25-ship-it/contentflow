# 分发侠·规则库（待审核）

本目录说明新增的“规则库”：条目、来源、审核流程和怎么在预览里看到它。

## 现状

- 共 13 条，**全部是“待审核”**。每条都只收 A 级来源：作者读过官方原文全文（或明确写出读到的范围），并写明出处、文号、发布/生效日期、读取日期和状态（现行 / 征求意见稿 / 已废止 / 待核实）。
- **默认不会显示任何条目**：页面显示“资料正在审核中”，入口也会隐藏。审核通过前，这些条目不会出现在正式界面，也不会被 AI 检索或引用。
- 预览（仅开发和审核用）：启动前设置环境变量 `NEXT_PUBLIC_SHOW_PENDING_LIBRARY=true`。

## 文件

- `runtime/web-cn/src/data/rule-library.json`：条目数据
- `runtime/web-cn/src/lib/rule-library.ts`：门禁、搜索筛选、日期和链接工具
- `runtime/web-cn/src/app/(main)/rules/`：列表页、加载态、详情页
- 入口：左侧导航“规则库”（`/rules`，已加入需要登录的路径）
- `runtime/web-cn/scripts/test-rule-library.mjs`：数据和门禁测试（已加入 `npm test`）

## 审核流程

沿用分发侠现有的资料审核方式（`review_rag_source.py`）：审核通过后把条目 `review_status` 改成“已审核”。本次没有改 RAG 的 `ALLOWED_ORIGINS`、没有往 `rag_cache` 里加文件，也没有动 `POLICY_REVIEWERS`（保持为空）。
